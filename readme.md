# GalOCRTranslator

一个基于 Python 和 PyQt5 的 AI 屏幕翻译工具。支持多种 OCR 引擎和 AI 模型，具有多窗口、高度自定义 UI 和透明度调节功能。

## 功能特点

*   **AI 翻译**: 可使用 OpenAI 格式实现翻译。
*   **多窗口支持**: 可以同时创建多个独立的翻译窗口，每个窗口可独立配置区域和大小。
*   **视觉定制**:
    *   独立的窗口大小调节（锁定/解锁）。
    *   顶部透明度控制（标题栏、按钮），支持全透明效果。
    *   按钮无文字设计，鼠标悬停显示提示。
    *   完全可调的背景色、文字颜色和 Alpha 通道。
*   **OCR 支持**: 集成 Tesseract OCR 和 PaddleOCR。
*   **快捷键**: 支持完全自定义的全键盘快捷键操作。
*   **托盘支持**: 最小化到系统托盘，常驻后台。

## 环境要求

*   Python 3.8+
*   Tesseract OCR 
*   PaddleOCR (做了名字，但没有进行测试)

## 安装步骤

1.  **克隆或下载项目代码**。
2.  **安装 Python 依赖库**：
    ```bash
    pip install PyQt5 pillow pytesseract paddlepaddle paddleocr keyboard requests
    ```
    或
    ```bash
     pip install -r requirements.txt
    ```
3.  **配置 Tesseract** (如果使用):
    *   下载并安装 Tesseract-OCR。
    *   在设置中填写 `tesseract.exe` 的完整路径 (例如 `C:\\Program Files\\Tesseract-OCR\\tesseract.exe`)。

## 使用说明

### 启动程序

直接双击 `main.py` 即可启动程序。启动后，托盘图标会出现在右下角。

### 操作指南

程序启动后，您会看到带有图标按钮的主窗口。以下是各个功能的详细操作说明：

1.  **基本窗口操作**:
    *   **移动窗口**: 按住窗口上方的标题栏并拖动。
    *   **调节窗口大小**: 鼠标移动到窗口标题栏**右上角**的小三角图标处，按住拖动即可改变大小（需在设置中取消勾选"锁定窗口大小"）。
    *   **右键菜单**: 在窗口任意位置点击鼠标右键，可以呼出菜单关闭窗口。

2.  **功能按钮** (鼠标悬停在按钮上可查看功能名称):
    *   📷 **截图**: 隐藏当前窗口，进入全屏截图模式。框选区域后，自动进行 OCR 并翻译。
    *   🌍 **翻译**: 直接对当前设置好的"截屏区域"进行截图并翻译。
    *   ⚓ **选区**: 仅修改当前预设的"截屏区域"，不进行翻译操作。
    *   👁 **指示**: 显示/隐藏屏幕上的红色虚线框，用于预览当前的截屏区域。
    *   🔄 **重试**: 使用上一张截图重新进行翻译，无需重新截屏。
    *   ⏯ **自动**: 开启/关闭自动翻译模式。开启后，程序会按照设定的间隔自动刷新翻译。（用ocr检测文本是否变化然后使用选择的翻译方式进行翻译）
    *   ⚙️ **设置**: 打开详细设置对话框。

3.  **设置对话框**:
    *   **API 设置**: OpenAI 格式的 API Key、模型名称、Prompt 等。
    *   **OCR & 翻译模式**: 选择 OCR 引擎（Tesseract 或 PaddleOCR）和翻译模式（OCR 后翻译 或 直接 Vision 翻译）。
    *   **窗口外观**:
        *   **顶部透明度**: 拖动滑块调节标题栏和按钮的不透明度（支持全透明）。
        *   **顶部背景色**: 调节顶部区域的背景颜色。
        *   **翻译框样式**: 调节翻译结果区域的背景色（支持 Alpha 通道）、文字颜色和边框。
    *   **窗口独立配置**: 每个窗口的页面允许独立设置宽高、锁定状态、截屏区域坐标以及专属的快捷键。

4.  **快捷键**:
    *   默认快捷键如下（可在设置中修改）：
    *   `Ctrl + Alt + Q`: 截图并翻译
    *   `Ctrl + Alt + T`: 翻译当前区域
    *   `Ctrl + Alt + R`: 重试
    *   `Ctrl + Alt + E`: 切换指示器
    *   `Ctrl + Alt + A`: 选区（不翻译）
